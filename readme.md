# DEX 代币交易平台

一个包含智能合约、交易前端、报价接口和事件同步服务的去中心化交易项目。

## 项目特点

- 基于 AMM 实现代币兑换，支持指定价格区间提供流动性。
- 使用 NFT 表示流动性头寸，管理流动性的增加、减少与费用领取。
- 提供同一交易对的多池路由、价格计算和兑换报价接口。
- Go 服务监听链上事件，将交易池、储备和流动性数据同步到数据库。
- 前端提供钱包连接、代币兑换、流动性管理和行情展示。

## 技术与目录

- `swap-contract/`：Solidity、Hardhat 智能合约。
- `dex-frontend/`：Next.js、React、TypeScript、Wagmi、Viem。
- `backend/`：Go、Gin 报价与查询 API。
- `sync/`：Go 链上事件索引与同步。
- `docs/`、`img/`：设计文档、流程图和学习资料。
